세트 기록 · 자세 평가

오늘 탑세트의 무게·반복·RPE를 기록하세요. 영상(선택)을 올리면 자세와 바벨 속도까지 평가하고, 이 기록과 느낌으로 다음 세션이 자동 설계됩니다. 영상은 기기 밖으로 전송되지 않습니다.

바벨 추적 (선택): 영상 위에서 ① 원판 중심 → ② 원판 위쪽 가장자리를 차례로 탭하세요. 속도·스티킹 포인트·모멘트암을 계산합니다.

자세 평가 기준

기본은 '지속 성장': 부하 위험(허리·어깨·무릎) → 세트 후반 무너짐 → 효율 → 가동범위 → 일관성 순으로 봅니다. 대회 준비 모드에서만 IPF 규정 판정을 표시합니다. 스타일에 따라 상체각·시작 자세 기준이 달라지니 내 스타일을 고르세요.

세부 기준값 편집

가민 파일 가져오기 (설정 없이 바로)

가민 커넥트에서 내보낸 파일을 선택하세요. 여러 개를 한 번에 선택할 수 있고, 같은 활동은 한 번만 반영됩니다.

  • 여러 러닝 한 번에: 가민 커넥트 웹 → 활동 → 모든 활동 → 오른쪽 위 CSV 내보내기
  • 자세한 기록 1개: 활동 상세 → ⚙ → 원본 내보내기 (.zip) 또는 TCX/GPX 내보내기

가민 자동 연동 (GitHub Actions)

GitHub Actions가 3시간마다 가민 러닝 기록을 가져와 암호화해 저장합니다. 저장소 Secrets에 넣은 DATA_PASSPHRASE를 입력하세요. (설정 방법은 README 참고)
