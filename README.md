# 하이브리드 트레이닝 (workout)

파워리프팅 · 근비대 · 러닝을 함께 하는 사람을 위한 웹앱입니다. 설치 없이 브라우저에서 동작하며, 모든 기록은 내 브라우저(localStorage)에만 저장됩니다.

## 기능

### 1. 주간 프로그램
**웨이트: 4일 로테이션**
| 순서 | 내용 |
|---|---|
| A | 오버헤드 프레스 + 스쿼트 (+ 레그프레스, 사이드 레터럴) |
| B | 벤치프레스 + 데드리프트 (+ 인클라인 덤벨, 푸시다운) |
| C | 등 + 팔 근비대 |
| D | 웨이트 휴식 |

- 설정의 '로테이션 시작일'이 A일이며, 이후 A→B→C→D가 계속 반복됩니다.
- 주차마다 강도가 바뀌는 **4주 웨이브**: 적응(75%) → 누적(80%) → 강화(85%) → 디로드(60%, 러닝 -30%)
- 트레이닝 맥스(기본 1RM의 90%) 기준이며, 4주마다 스쿼트·데드리프트 +5kg, 벤치 +2.5kg, OHP +1.25kg씩 자동 증량

**러닝: 가민 기록으로 자동 처방**
- 최근 4주 평균 거리의 +8%(지난주의 +15% 이내)로 이번 주 거리를 정함. 최근 부하가 급증했으면 동결
- 페이스: 가민 VO2max → 5K 환산 기록 → 이지/역치/인터벌 페이스
- 롱 런은 최근 4주 최장 거리 +2km 이내로 제한
- 배치 규칙: 템포/인터벌은 하체 없는 날(등+팔, 휴식일), 롱 런은 주말 휴식일 우선, 하체 날에는 이지 런만

### 2. 매일 파워리프팅 자세 평가
- **측면 영상 분석**: MediaPipe Pose로 관절을 추적하고 반복을 자동 인식해 반복마다 평가
  - 스쿼트: 깊이(고관절-무릎), 상체 기울기, 바 경로, 엉덩이 먼저 뜨는 동작
  - 벤치: 하단 전완 수직, 가동범위, 락아웃, 가슴 정지(퍼즈) 시간
  - 데드리프트: 시작 고관절 높이, 바-미드풋 거리, 엉덩이 먼저 뜨기, 바 경로, 락아웃·과신전
  - 세트 경향: 반복 간 상승 속도 저하(RPE 추정), 반복적으로 나타나는 문제
- **셀프 체크리스트 + RPE + 통증 여부**: 영상 없이도 매일 기록 가능
- 점수 = 영상 70% + 체크리스트 30%. 다음 세트 코칭 큐 제공
- 영상은 기기 안에서만 처리되며 업로드되지 않습니다

### 3. 러닝 후 평가 (가민 자동)
- 가민에 저장된 러닝을 자동으로 가져와 **그날 계획과 비교**해 평가 (계획: 이지 → 실제: 템포 강도면 지적)
- 가민 안정시 심박, 관측된 최대 심박으로 심박존 자동 보정
- 심박 예비량(HRR) 기반 존으로 처방 강도와 실제 강도 비교 (예: 이지 런을 너무 빠르게 달렸는지)
- 권장 페이스 대비 평가, 케이던스, RPE-심박 불일치(피로 신호)
- 훈련 부하(TRIMP), 급성/만성 부하비(ACWR), 유산소 효율(심박당 이동거리) 추세
- 레이스/기록 측정 시 VDOT과 5K·10K·하프 예상 기록 → 5K 기록 갱신 시 훈련 페이스 자동 업데이트
- 다음 날 헤비 스쿼트·데드리프트가 있으면 회복 조언

## 가민 연동 설정 (최초 1회)

가민은 개인용 공개 API가 없어서, GitHub Actions가 3시간마다 비공식 라이브러리([garminconnect](https://github.com/cyberjunky/python-garminconnect))로 로그인해 러닝 기록을 가져옵니다. 기록은 **AES-256으로 암호화**되어 `data/garmin.enc.json`에 저장되므로 저장소가 공개되어도 내용은 보이지 않습니다.

1. 저장소 **Settings → Secrets and variables → Actions → New repository secret** 에 3개 추가
   - `GARMIN_EMAIL`: 가민 커넥트 이메일
   - `GARMIN_PASSWORD`: 가민 커넥트 비밀번호
   - `DATA_PASSPHRASE`: 기록 암호화용 비밀번호 (새로 정하기, 앱에 입력할 값)
2. 이 코드가 `main` 브랜치에 있어야 예약 실행이 됩니다.
3. **Actions → Garmin sync → Run workflow** 로 첫 동기화 (이후 3시간마다 자동)
4. 앱 **설정 → 가민 연동** 에 `DATA_PASSPHRASE` 입력 → "저장하고 지금 불러오기"

**가민 2단계 인증(MFA)을 쓰는 경우**: 내 PC에서 한 번 실행해 토큰을 만들고 `GARMIN_TOKENS` 시크릿에 넣으세요.
```bash
pip install -r scripts/requirements.txt
GARMIN_EMAIL=... GARMIN_PASSWORD=... python scripts/garmin_sync.py --export-tokens
# 출력된 JSON 전체를 GARMIN_TOKENS 시크릿에 저장
```

동기화가 실패하면 Actions 탭의 실행 로그를 확인하세요. 비공식 방식이라 가민이 로그인 방식을 바꾸면 라이브러리 업데이트가 필요할 수 있습니다.

## 실행

ES 모듈을 사용하므로 파일을 직접 열지 말고 웹 서버로 실행하세요.

```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```

### 휴대폰에서 쓰기 (GitHub Pages)
비공개 저장소의 Pages는 GitHub 유료 플랜이 필요합니다. 무료라면 저장소를 공개로 바꿔도 가민 기록은 암호화되어 있고, 자세 평가 등 개인 기록은 브라우저에만 저장되어 저장소에 올라가지 않습니다.
저장소 **Settings → Pages → Branch: main / (root)** 를 선택하면 `https://hsh001580.github.io/workout/` 에서 사용할 수 있습니다. 휴대폰 브라우저에서 "홈 화면에 추가"하면 앱처럼 쓸 수 있습니다.

## 촬영 팁 (자세 평가)
- 카메라는 **정측면 90°**, 엉덩이 높이에 고정
- 머리부터 발끝까지, 바벨까지 화면에 모두 보이게
- 밝은 곳에서, 헐렁한 옷보다는 관절이 보이는 옷
- 한 세트 전체(최대 60초)를 촬영
