# 하이브리드 트레이닝 (workout)

파워리프팅 · 근비대 · 러닝을 함께 하는 사람을 위한 웹앱입니다. 설치 없이 브라우저에서 동작하며, 모든 기록은 내 브라우저(localStorage)에만 저장됩니다.

## 기능

### 1. 주간 프로그램 (코칭 엔진이 자동 조정)
**분할: 4일 반복**
| 순서 | 내용 |
|---|---|
| A | 스쿼트 + 오버헤드 프레스 (+ 하체·어깨 보조) |
| B | 벤치프레스 + 데드리프트 (+ 가슴·삼두 보조) |
| C | 등 + 팔 근비대 + **벤치 2회차** (약점 보완 변형 또는 퍼즈 벤치) |
| D | 웨이트 휴식 |

**블록 주기화 (8주)**: 축적 3주(6회, RPE 7→8, 볼륨↑) → 강화 3주(4→3회, RPE 8→8.5) → 실현 1주(싱글 RPE 8.5 + 2회) → 디로드 1주

**RPE 기반 자동조절**: 무게는 고정 %가 아니라 *추정 1RM(e1RM)* × 목표 반복·RPE로 계산합니다. e1RM은 기록한 탑세트(무게·반복·RPE, RPE가 없으면 바벨 속도로 추정한 RIR)의 최근 3세션 중앙값으로 계속 갱신됩니다.

**다음 세션 설계 규칙** (각 처방 아래 "왜 이렇게 처방했나요?"에 이유 표시)
- 지난 세션이 목표보다 RPE 1 이상 힘들었으면 → 강도 0.5↓, 백오프 1세트↓
- 목표보다 쉬웠고 자세 점수 80 이상 → 백오프 1세트↑ (무게는 e1RM 갱신으로 자동 상승)
- 세트 내 속도 손실 30% 초과 → 백오프 반복 1회↓
- 자세 점수 70 미만이거나 같은 결함이 반복 → 기술 우선 (탑세트 RPE 7.5 상한)
- 자세 결함·스티킹 포인트 → 변형 운동·보조 운동·큐 자동 처방 (예: 무릎 밸거스 → 템포 스쿼트+미니밴드, 힙 어브덕션 / 벤치 상단 스티킹 → 핀 프레스 / 데드 엉덩이 먼저 → 무릎 아래 퍼즈 데드)
- 통증 (오늘 컨디션의 통증 부위 또는 지난 세션 통증) → 통증 없는 대체 운동, 무게 20%↓
- 오늘 컨디션 (수면·에너지·근육통) 낮음 → 강도·백오프 세트↓
- 전날 강한 러닝 → 하체 백오프 1세트↓
- **피로 신호 2개 이상** (RPE 초과 반복, e1RM 5% 하락, 통증 반복, 컨디션 저하, 러닝 부하 급증) → 디로드 자동 배치

**러닝**: 가민 기록의 최근 4주 거리·VO2max(또는 VDOT)·최장 거리로 주간 거리와 페이스를 정하고, 블록 단계에 맞춰 거리 배율과 품질 세션 종류를 바꿉니다. 템포·인터벌은 하체 없는 날에만 배치합니다.

### 2. 매일 파워리프팅 자세 평가
영상은 기기 안에서만 처리되며 업로드되지 않습니다. 촬영 각도를 고르면 그에 맞는 항목을 평가합니다.

| 촬영 각도 | 방식 | 평가 항목 |
|---|---|---|
| 측면 90° | 2D | 깊이, 상체각, 엉덩이 먼저 뜨기, 락아웃, 벤치 퍼즈, OHP 레이백·무릎 반동 + (원판 지정 시) 모멘트암·미드풋 정렬 |
| 후방 대각선 45° | 3D 추정 | 측면 항목 + 무릎 밸거스, 무릎-발끝 정렬, 힙 시프트, 골반 기울기, 몸통 회전, 좌우 굴곡 차이, 뒤꿈치 들림, 바 기울기, 벤치 팔꿈치 벌어짐, OHP 옆 기울기 |
| 정면·후면 | 2D | 좌우 항목만 (밸거스, 힙 시프트, 골반, 뒤꿈치, 바 기울기) |

**준비 구간 자동 제외**: 언랙, 걸어 나오기·들어가기, 랙에 걸기, 손 놓기 구간을 자동으로 찾아 분석에서 뺍니다. 발이 고정되어 있고(발목 속도 < 0.25 다리길이/초) 바를 쥔 자세(OHP: 손목이 어깨 근처 이상, 스쿼트: 손목이 어깨 근처, 벤치: 바가 얼굴 쪽 랙 위치가 아님)인 구간 중 움직임이 가장 많은 구간만 분석하며, 제외한 시간은 결과 요약에 표시됩니다.

**바벨 추적 (원판 지정)**: 첫 화면에서 원판 중심 → 원판 위쪽 가장자리를 탭하면 원판을 따라가며 계산합니다.
- 반복별 평균·최고 동심성 속도, 세트 내 속도 손실, 마지막 반복 속도로 RIR/RPE 추정
- 스티킹 포인트(상승 중 속도 급감 지점)와 그 순간의 원인 진단: 상체 숙여짐, 고관절 모멘트암 증가, 무릎 모임, 힙 시프트 → "힘이 새는 지점"
- 측면 촬영 시 고관절·무릎 모멘트암, 바-미드풋 편차(앞꿈치/뒤꿈치 쏠림), 벤치 락아웃 바-어깨 정렬
- 서로 다른 무게 기록이 쌓이면 하중-속도 관계로 1RM 추정

**브레이싱 근사 지표**: 복압 자체는 영상으로 측정할 수 없어 다음 신호로 추정합니다.
- 반복 직전 정지 시간 (숨을 다시 채우고 복압을 잡을 시간이 있었는지)
- 몸통 길이 감소 (등이 말리거나 복압이 풀려 몸통이 접힘)
- 상승 중 상체가 0.2초 사이 급격히 꺾임

**판정 기준 프리셋** (설정 탭): 균형(기본), 파워리프팅 대회(엄격), 로우바·고관절 주도, 하이바·상체 세우기, 관대한 무릎 기준. 모든 기준값은 직접 수정할 수 있습니다.

**기록 탭**: 종목별 자세 점수, 무릎 밸거스·힙 시프트, 바벨 속도 추이 그래프

점수 = 영상 70% + 셀프 체크리스트 30%. 반복의 절반 이상에서 나온 문제는 '반복적인 문제'로 추가 감점됩니다.

### 3. 러닝 후 평가 (가민 자동)
- 가민에 저장된 러닝을 자동으로 가져와 **그날 계획과 비교**해 평가 (계획: 이지 → 실제: 템포 강도면 지적)
- 가민 안정시 심박, 관측된 최대 심박으로 심박존 자동 보정
- 심박 예비량(HRR) 기반 존으로 처방 강도와 실제 강도 비교 (예: 이지 런을 너무 빠르게 달렸는지)
- 권장 페이스 대비 평가, 케이던스, RPE-심박 불일치(피로 신호)
- 훈련 부하(TRIMP), 급성/만성 부하비(ACWR), 유산소 효율(심박당 이동거리) 추세
- 레이스/기록 측정 시 VDOT과 5K·10K·하프 예상 기록 → 5K 기록 갱신 시 훈련 페이스 자동 업데이트
- 다음 날 헤비 스쿼트·데드리프트가 있으면 회복 조언

## 가민 기록 가져오기

자동 동기화는 러닝뿐 아니라 가민이 제공하는 훈련·회복·신체 데이터를 함께 가져와 코칭에 씁니다.

| 분류 | 데이터 | 코칭에서 쓰는 곳 |
|---|---|---|
| 회복 | 수면 점수·단계·수면 중 HRV·SpO2·호흡, HRV 상태, 바디 배터리, 스트레스, 안정시 심박, 트레이닝 레디니스 | 컨디션을 직접 기록하지 않은 날 **자동 컨디션** (수면 점수 → 수면, 레디니스/바디 배터리 → 에너지), 피로 신호 |
| 부하 | 트레이닝 상태, 급성/만성 부하·ACWR | 디로드 판단, 보조 운동 볼륨 |
| 능력 | VO2max 추이, 레이스 예측, 젖산 역치, 지구력·언덕 점수, 피트니스 나이, 심박존, 근력 1RM 추정 | 레이스 예측 5K → 훈련 페이스, 심박존 최대 심박 → 강도 판정 |
| 활동 | 모든 활동 (근력 운동은 세트·반복·무게) | 기록 탭 표시 |
| 신체 | 체중·체지방·근육량·BMI | 기록 탭 추이 |

가민 피로 신호: HRV 낮음·불균형 3일 이상(최근 5일), 레디니스 35 미만 2일 이상(최근 3일), 안정시 심박이 평소보다 5 이상 높은 날 2일 이상, 트레이닝 상태 과훈련·부담·비생산. 다른 피로 신호와 합쳐 2개 이상이면 디로드가 자동 배치됩니다.

처음에는 활동 180일·건강 지표 90일(수면 상세 30일)을 가져오고, 이후에는 최근 3일만 갱신합니다. 기기가 지원하지 않는 항목은 건너뜁니다.


**방법 1: 파일 가져오기 (설정 없이 바로)** — 앱 설정 탭 → "가민 파일 가져오기"
- 여러 러닝 한 번에: 가민 커넥트 웹 → 활동 → 모든 활동 → **CSV 내보내기** (영문·한글 헤더 지원)
- 자세한 기록: 활동 상세 → ⚙ → **원본 내보내기**(.zip 안의 .fit) 또는 TCX/GPX
- 같은 활동은 여러 번 가져와도 한 번만 반영됩니다.

**방법 2: 자동 동기화 (GitHub Actions)** — 아래 설정을 마치면 3시간마다 자동. 비밀값이 없으면 작업은 실패하지 않고 건너뜁니다.


가민은 개인용 공개 API가 없어서, GitHub Actions가 3시간마다 비공식 라이브러리([garminconnect](https://github.com/cyberjunky/python-garminconnect))로 로그인해 러닝 기록을 가져옵니다. 기록은 **AES-256으로 암호화**되어 `data/garmin.enc.json`에 저장되므로 저장소가 공개되어도 내용은 보이지 않습니다.

1. 저장소 **Settings → Secrets and variables → Actions → New repository secret** 에 3개 추가
   - `GARMIN_EMAIL`: 가민 커넥트 이메일
   - `GARMIN_PASSWORD`: 가민 커넥트 비밀번호
   - `DATA_PASSPHRASE`: 기록 암호화용 비밀번호 (새로 정하기, 앱에 입력할 값)
2. 이 코드가 `main` 브랜치에 있어야 예약 실행이 됩니다.
3. **Actions → Garmin sync → Run workflow** 로 첫 동기화 (이후 3시간마다 자동)
4. 앱 **설정 → 가민 연동** 에 `DATA_PASSPHRASE` 입력 → "저장하고 지금 불러오기"

**가민 2단계 인증(MFA)을 쓰는 경우**: 내 PC에서 한 번 실행해 토큰을 만들고 `GARMIN_TOKENS` 시크릿에 넣으세요.
```bash
pip install -r scripts/requirements.txt
GARMIN_EMAIL=... GARMIN_PASSWORD=... python scripts/garmin_sync.py --export-tokens
# 출력된 JSON 전체를 GARMIN_TOKENS 시크릿에 저장
```

동기화가 실패하면 Actions 탭의 실행 로그를 확인하세요. 비공식 방식이라 가민이 로그인 방식을 바꾸면 라이브러리 업데이트가 필요할 수 있습니다.

## 실행


### 휴대폰에서 쓰기 (GitHub Pages)
비공개 저장소의 Pages는 GitHub 유료 플랜이 필요합니다. 무료라면 저장소를 공개로 바꿔도 가민 기록은 암호화되어 있고, 자세 평가 등 개인 기록은 브라우저에만 저장되어 저장소에 올라가지 않습니다.
저장소 **Settings → Pages → Branch: main / (root)** 를 선택하면 `https://hsh001580.github.io/workout/` 에서 사용할 수 있습니다. 휴대폰 브라우저에서 "홈 화면에 추가"하면 앱처럼 쓸 수 있습니다.

## 촬영 팁 (자세 평가)
- 휴대폰을 **엉덩이 높이에 수평으로 고정** (기울어지면 3D 추정과 속도가 틀어짐)
- 머리부터 발끝까지, 원판까지 화면에 모두 보이게
- 후방 45°: 몸 뒤쪽 대각선 2~3m. 양쪽 무릎과 발이 모두 보여야 함
- 벤치를 대각선에서 볼 때는 머리 쪽 위에서
- 밝은 곳에서, 관절이 보이는 옷 / 한 세트 전체(최대 60초)

## 주의
- 3D 좌표는 카메라 한 대로 추정한 값이라 각도 오차가 5~10° 있을 수 있습니다. 그래서 대부분의 좌우 지표는 **서 있는 자세 대비 변화량**으로 판정합니다. 같은 위치에서 찍은 내 기록끼리 비교할 때 가장 믿을 만합니다.
- 척추 관절점이 없어 고관절이 앞으로 접히는 정도(butt wink)나 허리가 말리는지는 몸통 길이 변화로만 간접 추정합니다.
- 속도 기반 RIR·1RM은 일반적인 문헌값을 쓰므로 개인차가 큽니다.
- 통증이 있으면 코치나 의료 전문가와 상담하세요.
